# Learn Typography by Building a Nutrition Label

A freeCodeCamp practice project. Typography is the art of styling text so it reads easily and suits its purpose. This project uses it to build a nutrition facts label with plain HTML and CSS.

## What it covers

- Loading and using a web font (Open Sans, weights 400/700/800)
- Font weight, size, letter spacing and line height
- Laying out rows with Flexbox (`justify-content: space-between`)
- Rules and dividers built from borders and filled blocks
- Hanging indents with a negative `text-indent`

## Run it

There's no build step. Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server
```

Then visit <http://localhost:8000>.

## Files

| File         | Purpose                         |
| ------------ | ------------------------------- |
| `index.html` | Label markup                    |
| `styles.css` | All styling (uses CSS variables) |
